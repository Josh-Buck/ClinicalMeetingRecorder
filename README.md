# Clinical Meeting Recorder

DSCI 441 Project, Spring 2026

Josh Buck & Alrakhmet Muratbek - Lehigh University

## Overview

A Streamlit web application that turns doctor-patient conversation transcripts into structured clinical predictions using classical machine learning. Users paste a dialogue and the app predicts the clinical note section type, whether the patient needs follow-up, and the severity level (high vs not-high).

This project was built for the DSCI 441 course, so the central analytical work is all classical ML that we covered in class: Naive Bayes, Logistic Regression, LDA, SVM, Decision Trees, Bagging, Random Forest, XGBoost, Stacking, PCA, K-Means, and regularized regression (OLS, Ridge, Lasso). Pre-trained tools (Ollama) are only used as preprocessing/labeling helpers, not as the analytical core.

## Pipeline

```
Transcript -> TF-IDF + dialogue features (+ entity features) -> Classical ML models -> Predictions
```

For the severity and follow-up tasks, training labels were generated by Ollama (llama3.1:8b) running locally on the dialogues. After labels were generated once, all training and inference uses only classical ML.

## Datasets

- MTS-Dialog (primary): 1,201 training + 100 validation + ~400 test doctor-patient dialogues paired with clinical note section labels. Source: https://github.com/abachaa/MTS-Dialog
- ACI-BENCH (supplementary): 67 full clinical encounters with notes and patient metadata. Source: https://github.com/microsoft/clinical_visit_note_summarization_corpus

See `data/readme_data.txt` for instructions on placing the data files.

## Models and Results

Section type classification (6 classes, MTS-Dialog):

| Model | Macro F1 (5-fold CV) |
|---|---|
| Logistic Regression (best, C=0.1, balanced) | 0.591 |
| SVM Linear | 0.580 |
| Stacking ensemble | 0.594 |
| SVM RBF | 0.535 |
| XGBoost (tuned) | 0.535 |
| Bagging (over decision trees) | 0.523 |
| LDA | 0.481 |
| Naive Bayes | 0.439 |
| Decision Tree | 0.436 |
| Random Forest | 0.412 |

Validation: bootstrap resampling (n=200), paired t-tests, Kruskal-Wallis test (p < 0.001 for dialogue length differing across section types).

Performance improvements over baseline (notebook 12):
- Baseline: 0.579
- Word + character n-grams: 0.597
- SMOTE + word + char: 0.615

Other tasks:
- Follow-up prediction (binary, LogReg): F1 = 0.747, ROC AUC = 0.874
- Severity classification (binary high vs not-high, SVM Linear): F1 = 0.511, ROC AUC = 0.786
- Note length regression (Lasso alpha=0.1): R^2 = 0.797

Cohen's kappa between LLM and keyword severity labels: 0.017 (essentially no agreement, which puts a label-noise ceiling on the severity classifier).

## Required Packages

Install via pip:

```
pip install -r requirements.txt
```

Main dependencies: streamlit, pandas, numpy, scikit-learn, scipy, xgboost, joblib, matplotlib, seaborn, imbalanced-learn.

The notebooks that use Ollama (notebooks 03, 05) require Ollama installed locally with the `llama3.1:8b` model. The other notebooks don't need Ollama since they use the saved entity extractions in `data/processed/mts_entities.json`.

## How to Run

To run the Streamlit app:

```
streamlit run app.py
```

This loads the three saved models from `models/` and serves the prediction UI on localhost. Paste a doctor-patient transcript and the app returns section type, follow-up prediction, and severity prediction.

To run the notebooks: open Jupyter and execute notebooks in order. Notebooks 01 to 12 are designed to be run independently if the saved models and processed entity file are already present. If you want to regenerate everything from scratch, run them in numerical order.
