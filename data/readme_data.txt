Data folder for the Clinical Meeting Recorder project.

The repository ships with the data files already in place. The instructions
below explain where each file came from in case you need to redownload.

Folder layout:

    data/
        raw/
            MTS-Dialog-TrainingSet.csv
            MTS-Dialog-ValidationSet.csv
            MTS-Dialog-TestSet-1-MEDIQA-Chat-2023.csv
            MTS-Dialog-TestSet-2-MEDIQA-Sum-2023.csv
            aci-bench/
                train.csv
                train_metadata.csv
                valid.csv
                valid_metadata.csv
        processed/
            mts_entities.json


MTS-Dialog (primary dataset)
----------------------------
1,201 training plus 100 validation plus around 400 test doctor-patient
dialogues paired with clinical note section labels.

Source: https://github.com/abachaa/MTS-Dialog

To redownload:
    git clone https://github.com/abachaa/MTS-Dialog.git
Then copy the four CSV files (training, validation, two test sets) into
data/raw/.


ACI-BENCH (supplementary dataset)
---------------------------------
67 training plus 20 validation full clinical encounters with notes and
patient metadata (age, gender, chief complaint).

Source: https://github.com/microsoft/clinical_visit_note_summarization_corpus

To redownload:
    git clone https://github.com/microsoft/clinical_visit_note_summarization_corpus.git
Then copy train.csv, train_metadata.csv, valid.csv, valid_metadata.csv into
data/raw/aci-bench/.


Processed entities cache
------------------------
data/processed/mts_entities.json holds the LLM-extracted entities (chief
complaint, symptoms, diagnoses, medications, severity, follow-up flag) for
all 1,200 training dialogues. This file is generated by notebook 05 using
Ollama with the llama3.1:8b model. It is checked into the repository so
downstream notebooks (07, 08, 09, 11, 12) can run without needing Ollama.

If you want to regenerate it from scratch (results may vary from my run):
    1. Install Ollama: https://ollama.com
    2. Pull the model: ollama pull llama3.1:8b
    3. Start the server: ollama serve
    4. Run notebook 05 end-to-end (Can take a very long time depending on your machine)
